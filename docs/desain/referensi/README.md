Format nama: `NN-<sumber/brand>-<isi gambar>.jpg`. Semua milik pembuatnya masing-masing; dipakai sebagai
acuan selera, **jangan disalin** komposisi atau elemennya mentah-mentah, dan tidak pernah tayang di situs.

## Catatan saringan
- 33 (Steply) dan 04/05/06 (Sunlight) memakai lime terlalu banyak. Untuk Atapura lime ≤5% layar.
- 03 (ungu) dan 21 (merah) diambil tipografinya saja, bukan warnanya.
- Latar gelap + lime sering muncul di desain buatan AI. Pembedanya: gelap hijau pinus, foto asli memimpin,
  bagian informasi (harga, tabel, artikel) tetap di latar terang.
